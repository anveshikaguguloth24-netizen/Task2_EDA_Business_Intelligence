# Task 2 – Exploratory Data Analysis & Business Intelligence

## Objective
Perform exploratory data analysis on customer purchase data and generate business insights.

## Dataset Columns
customer_id, name, gender, birth_year, purchase_date, amount, city, age, purchase_month, amount_category

## Tools Used
Python  
Pandas  
Matplotlib  
Seaborn  
Google Sheets (Dashboard)

## Work Done
- Data analysis using Python
- Visualization of patterns
- SQL queries for business insights
- Dashboard creation

## Key Insights
- Hyderabad has the highest purchase revenue.
- Medium purchase category is most common.
- Customers aged 24–27 spend more frequently.
